```markdown
# Portfolio Website

Personal portfolio site built by hand with HTML, CSS, JavaScript and PHP, with a blog
backed by a MySQL database.

Built before I moved to frameworks — everything here is written directly rather than
generated, including the page layout, the styling and the PHP that talks to the database.

## Running it locally

Needs PHP and MySQL. Import the schema, set the database credentials in the config,
and serve the directory with `php -S localhost:8000`.
```
